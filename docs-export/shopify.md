# Shopify

Connect Shopify to your v0 applications for e-commerce functionality.

## Features

- Generate Shopify storefronts
- Connect Shopify development stores
- Handle product data and checkout

## Commerce Mode

When publishing, v0 may prompt you to connect a Shopify development store.
