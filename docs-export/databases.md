# Databases

Integrate databases into your v0 applications.

## Available Integrations

- **Neon** - Serverless PostgreSQL
- **Supabase** - PostgreSQL with auth and realtime
- **Upstash for Redis** - Serverless Redis
- **Blob** - File storage

## Adding a Database

Open **Project menu** → **Settings** → **Integrations** and install the database integration.

## Connecting

v0 automatically configures the database connection when you prompt it to add a database.
