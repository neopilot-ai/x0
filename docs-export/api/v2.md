# v2 API

The v2 API provides type-safe methods for creating chats, sending messages, managing MCP servers, handling webhooks, and more. All endpoints are prefixed with `/v2`.

## Quick Reference

| Category | Endpoints | Description |
|----------|-----------|-------------|
| **Chats** | 21 | Create, list, get, update, delete, deploy, duplicate chats |
| **Messages** | 9 | Send, resolve, stream, stop messages |
| **MCP Servers** | 5 | Create, list, get, update, delete MCP servers |
| **Webhooks** | 5 | Create, list, get, update, delete webhooks |
| **Settings** | 2 | Get and set trusted preview hosts |
| **Usage** | 3 | Activity, events, summary |
