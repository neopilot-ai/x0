# FAQs

### What is v0?

v0 is an AI agent that helps anyone create real code and full-stack apps and agents.

### How do I get started?

Visit [v0.app](https://v0.app), sign in, and start a new chat.

### Can I use v0 for production?

Yes! v0 can deploy to production with one click via Vercel.

### What can I build?

Anything from landing pages, dashboards, ecommerce stores, AI apps, to full-stack applications.

### Do I need to write code?

No! v0 generates code from natural language descriptions, but you can edit the code if needed.

### How does v0 handle errors?

v0 automatically fixes errors in your code with intelligent diagnostics.
