# Code Editing

Edit generated code directly in v0's Code view. Switch between the visual preview and the code editor to refine your application.

## Switching Views

1. Select the **Code** tab in the preview toolbar
2. Make direct edits to the generated code
3. Ask for changes in natural language: "Add a search bar to the product list"

## Editor Features

The code editor provides a full-featured editing experience:

- **Syntax highlighting** — Code is colorized by language
- **Line numbers** — Lines are numbered for easy reference
- **Find and replace** — Search within the file
- **Global search** — Search across all files in the project
- **File explorer** — Navigate and manage project files

### Editor Toolbar

The editor toolbar provides quick access to editing features:

- **Copy File** — Copy the current file to your clipboard
- **Toggle Diff View** — Switch between the full file and a diff view
- **Split Layout** — Toggle split view to see two files side by side

### Keyboard Shortcuts

- **Cmd/Ctrl + S** — Save and apply changes

## Inline Editing

Edit code directly in the preview interface. v0 can refine code based on your feedback. Make changes directly in the code editor and ask v0 to implement them.

## Design Mode vs Code Mode

- **Code Mode** - Direct code editing and iteration
- **Design Mode** - Visual styling and layout editing
