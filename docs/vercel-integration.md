# Vercel Integration

Integrate v0 with your Vercel projects for deployment and management.

## Features

- Deploy generated apps to Vercel
- Connect Vercel projects to v0
- Manage deployments from v0
- Vercel Analytics integration

## Deployment

When you publish from v0, the app is deployed to Vercel automatically.
