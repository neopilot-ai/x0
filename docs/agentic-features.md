# Agentic Features

v0 includes autonomous agent capabilities for web search, site inspection, error fixing, and external tool integration.

## Web Search

The agent can search the web to gather information for your projects.

## Site Inspection

The agent can inspect running applications to understand their structure.

## Error Fixing

v0 automatically diagnoses and fixes errors in generated code with intelligent diagnostics.

## External Tool Integration

Connect external tools and MCP servers to extend the agent's capabilities beyond code generation.
