# Custom Domains

Add custom domains to your v0 applications.

## Adding a Domain

On first publish, select a domain in the **Domains** step. Or navigate to **Project menu** → **Settings** → **Domains**.

## Connecting a Custom Domain

1. Purchase a domain via [Vercel Domains](https://vercel.com/domains)
2. Add the domain in v0 settings
3. Configure DNS records

## Domain Management

Manage all domains from **Project menu** → **Settings** → **Domains**.
